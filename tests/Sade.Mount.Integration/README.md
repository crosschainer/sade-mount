VehiclePhysics.cs is a trusted `run_csharp` script for a running s&box editor with the current SADE mount installed. Discover `run_csharp` with the CLI, then pass the script's absolute path. It loads six real mounted vehicle families into an isolated temporary scene, advances the engine's physics, checks source mass, ground balance, propulsion, flotation and takeoff, and destroys the temporary scene. It leaves the active scene and camera unchanged. The disabled test driver supplies deterministic inputs through the mount controller; seat interaction is a separate live test.

VehicleSeats.cs checks offline driver and passenger entry, occupied-seat rejection, engine sitting mode, disabled seated collision, passenger/driver separation, clear exits, and restored walking physics. It uses the actual mounted Infernus prefab and engine PlayerControllers in a temporary scene. Run after installing the current mount, before joining a network session. Network ownership and replication still require a multiplayer test.
