# v0.3

San Andreas is now a map you can explore in Sandbox. Nearby streets, buildings and
scenery stream in as you move, with one San Andreas entry and a Grove Street
preview in the map picker.

- **Streamed world:** 79,664 exterior placements, indexed by their actual bounds.
  Terrain and buildings load ahead of smaller detail, and distant objects unload.
- **Walkable streets:** detailed surface collision replaces coarse hulls that
  blocked roads. World-baked ground meshes also get correctly aligned collision.
- **Surface sounds:** original COL material IDs and `surfaud.dat` select different
  footsteps for grass, concrete, metal and other surfaces. Sand and gravel use
  s&box's dirt surface; long grass uses grass. Ambiguous geometry uses a reported
  fallback to its original dominant audio group.
- **Loose props:** suitable objects from `object.dat` have physical bodies and
  work with Sandbox's physgun. Large pieces, terrain, buildings and structural
  object types stay fixed. Moved and frozen poses survive streaming in the same
  map session.

After enabling the mount, open **Sandbox → New game → Map**, choose
**GTA San Andreas — The Definitive Edition** under **Source**, then select
**San Andreas**. You start at Grove Street; the other cities are part of that same
world. Existing map and asset paths still resolve.

Map support is experimental. Water, interiors, traffic, distant skyline proxies
and a generated navigation mesh are not included yet. First visits take longer
while assets convert. The idle cache budget does not cap resources still in view,
and individual mesh uploads can exceed the streaming frame budget. Changes to
map props do not survive a map reload or Sandbox save, and multiplayer prop
replication has not been verified.

To update, close s&box and replace `sbox/mount/sade` with the `sade` folder from
the ZIP. Keep your `sade.json` if you customized it. GTA San Andreas — The
Definitive Edition must remain installed separately. The download contains no
extracted game assets or s&box engine assemblies.
